Drifting particles

Dots drift across a canvas and are linked by a line whenever two of them pass close to each other. One file, no dependencies, about forty lines of logic.

If your system asks for reduced motion, the canvas is drawn once and left still. The animation also pauses while this tab is in the background.

How it works

Each dot keeps a position and a small velocity. Every frame moves the dots, wraps them around the edges, then compares every pair: if two dots are closer than the link distance, a line is drawn with an opacity that fades as the distance grows. 

var dx = a.x - b.x;
var dy = a.y - b.y;
var d = Math.sqrt(dx * dx + dy * dy);

if (d < link) {
  ctx.globalAlpha = 1 - d / link;
  ctx.beginPath();
  ctx.moveTo(a.x, a.y);
  ctx.lineTo(b.x, b.y);
  ctx.stroke();
}

Colours come from the same custom properties as the rest of the site, so the demo is coloured from the site's tokens rather than from hard-coded values of its own.

Using this as a template

  1. Copy demos/hello-canvas/ to demos/your-demo/.
  2. Edit the title, description and canonical URL in the <head>.
  3. Replace the script, keeping the resize and visibility handling.
  4. Add a card to demos/index.html and a URL to sitemap.xml.

Why the canvas is described

A canvas is invisible to assistive technology, so it carries a role="img" and a label that says what it shows. Purely decorative motion should instead be hidden with aria-hidden="true".
