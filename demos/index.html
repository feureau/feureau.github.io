House rules for demos

No dependencies

Plain HTML, CSS and JavaScript only, so a demo keeps working without maintenance.

No network calls

Nothing loads from a third-party host, which keeps the page fast and private.

Keyboard and motion

Anything interactive is reachable by keyboard, and animation respects reduced-motion settings.
